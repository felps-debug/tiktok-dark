# Animated character from a photo
Locate the repository root. Read AGENTS.md and docs/workflows/profilepic.md, then execute that workflow using the current request and attached or accessible reference photo. The invocation requests image generation, not just a prompt. Ask for a missing image and wait; inspect the reference before generating. Preserve likeness, produce one front candidate, and wait for approval. Never claim a prompt is a rendered image or assume an image tool exists.
