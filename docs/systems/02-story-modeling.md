# 02 — Narrative DNA and collaborative modeling
## Role
Help the user explore and develop a direction while preserving the chosen narrative functions.
## Input and reads
Complete reference analysis, evidence limitations, existing series constraints and requested audience/language/duration.
## Process
1. Separate structural functions from surface details. Extract this reference's DNA rather than applying a fixed template.
2. Offer 3–4 genuinely different directions where useful, each with universe, conflict, functional equivalents, hook/ending mapping and tradeoffs.
3. Explicitly allow a custom direction or combination. If the user already chose a direction, record it and skip redundant choice.
4. STOP for the choice before drafting a completed adaptation.
5. Develop the chosen story collaboratively: roles, world rules, causal sequence, tonal/localization choices and ending.
6. Map original beat functions to adaptation events. Flag intentionally changed functions.
7. Estimate duration using concise provisional dialogue and the reference's pacing; avoid expansion through repeated exposition.
8. Deliver the complete story as a draft and ask for approval. It is not yet a shot list or visual prompt.
## Outputs
directions.md, then historia.md using templates/story.md; state.selected_direction with user's confirmed choice.
## Check
No compulsory loss, mentor, school, species, violence style or cliffhanger unrelated to this reference.
Localization should make context and language natural without rewriting the approved plot.
