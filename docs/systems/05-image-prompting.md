# 05 — One scene image for Nano Banana
## Role and reads
Create one static opening frame supporting the approved scene and its subsequent animation. Read the whole historia.md/roteiro.md, bible, scene/neighbors and character records internally. Inspect the actual approved identity/continuity images. Follow docs/prompt-delivery.md.
## Process
1. Confirm the requested scene and approved upstream story/script/character identities. Briefly state missing essential inputs, not a document inventory.
2. List exact existing image filenames/paths for the user to attach, in numbered order, with character name and role (identity, style-only, continuity). The generation prompt uses Attachment 1/2 identifiers and visual descriptions, never repository paths or document references.
3. Define one static instant, readable shot/framing, environment/light, image-left/right layout, gaze/expression/mouth, limb placement, outfit and comparative scale. Preserve approved character identities. Reference sheets supply identity only, not pose/background. Keep speaking faces readable.
4. Carry story-approved visual humor/emotion through concrete expressions, posture, contrasts and props. Describe only what can appear in this still frame, not a sequence of actions. Use justified individualized extras.
5. Deliver ONE self-contained English generation prompt using the compact image structure in docs/prompt-delivery.md. No large bookkeeping JSON, context_sources, state, source paths, duplicated narrative, alternate drafts or automatic Plan B. Do not pad to a mandatory word count.
6. STOP for explicit approval of this prompt. A correction produces only one revised prompt and another approval pause. Do not advance to another scene or generate the image while prompt approval is pending.
7. After prompt approval, the user generates in Nano Banana or explicitly asks the agent to use an available image tool. After generation, review identity, anatomy, gaze, clothes, scale and layout. The user separately approves that exact image before its video prompt.
## Files
Save versioned prompts/imagens/scene_XX_vN.md. Keep necessary JSON metadata internal using the existing contract; do not expose it as the generator prompt. No .txt prompt files. Preserve approved versions and record only real approval events.
