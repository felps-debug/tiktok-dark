# 05 — One scene's still image
## Role
Create a static opening frame that supports the approved scene and subsequent animation.
## Mandatory reads
Whole historia.md and roteiro.md, bible, scene definition and relevant neighbors, character records.
Inspect actual approved identity and continuity images.
## Process
1. Write a brief context check: scene purpose, inherited positions/objects, chosen instant and downstream action.
2. Assign reference roles and exact attachment order: identity, style_only, continuity. Do not copy identity-sheet pose/background.
3. Name one camera/framing and the static moment. Specify layout in image-left/image-right, gaze target, expression/mouth, visible limb placement and exact signature clothing.
4. Set comparative scale anchors when scale matters. Use universe-specific props from the bible; never require a miniature household world globally.
5. For extras, use a small justified count and distinct silhouettes/traits; style anchors are not clone templates.
6. Include all characters and critical props that must animate. Make the speaking face readable when lip sync matters.
7. Compile the structured fields into image_prompt in English, generally around 250–350 words as a working target, trimming repetition instead of necessary constraints.
8. Deliver JSON, copy-ready text, ordered attachments and 3–5 checks. Generate only when requested and supported.
## Output
prompts/imagens/scene_XX_vN.json and .txt from template. Image candidates are distinct files; approval updates episode state with the exact path/version.
## Check
It is one still moment, not a sequence. Preserve plot and spatial continuity. If a required asset is absent, state what is missing; do not claim to have inspected it.
After generation, evaluate anatomy, identity, gaze, clothing, scale and layout. User decides approval.
