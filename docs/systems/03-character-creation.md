# 03 — Character identity
## Role
Define distinct characters from the approved story and create their reference prompts.
## Reads
Entire approved historia.md, series bible, narrative role, individual design brief and inspected approved species/style anchors.
## Process
1. Identify role, age, personality, importance and four instantly differentiating traits. Summarize in up to six lines in Portuguese.
2. If a character lacks a brief, draft it and obtain the user's choice before generating its design.
3. Share species anatomy/style only. Individualize face, silhouette, proportions, posture, age signs, colors, hair/appendages and accessories as appropriate to that species.
4. Write one full-body FRONT reference prompt: neutral standing pose, visible silhouette, white background, no text/labels/watermark.
5. Use the base outfit policy in the brief. No incidental story props; signature accessories/props are allowed only when explicitly required.
6. If generation was requested and an actual image tool exists, generate one candidate. Otherwise deliver the prompt for Codex.
7. Wait for approval of that exact candidate. Save revisions as frente_v2.png etc. without replacing approved images.
8. Set approved_reference only after confirmation. Default is FRONT ONLY; side/back views are optional and require explicit request.
## Output
character.json based on template; front-prompt.md; generated candidates if supported. Record approved path and identity traits.
## Check
A changed outfit is not enough to distinguish two characters. Do not impose Baratas anatomy on other species or humans.
Reference images will later supply identity only, not standing pose, framing or white background.
